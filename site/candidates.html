Candidate explorer

Every row of the repository's full-sky candidate table and of the table of earlier-search candidates. By default only the tiers the README counts as candidates are shown.

Open a row (the arrow, or Enter on it) to see that candidate's vetting plot from its folder in the repository. These are planet candidates, not confirmed planets. FPP is the TRICERATOPS false-positive probability from TESS data alone; the table shows the Gaia-limited, centroid-combined value (FPP_gc) where available, then FPP_c, then FPP. The statistical-validation threshold is FPP < 0.015 and also needs high-resolution imaging. The earlier-search table has no T14, depth or Tmag of its own; where the same signal is in the ephemeris table those values are filled in, and Teff, distance and MES are left blank.
